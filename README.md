# 假期最优解 V2

面向上海出发、前往加拿大或日本的自由行用户，根据兴趣偏好、假期约束和价格容忍度生成三类可比较方案。

## 本地运行

```bash
node server.cjs
```

浏览器打开 `http://localhost:4173`。

如果只是查看演示版交互，也可以直接打开 `index.html`。页面会在报价 API 不可用时自动使用本地 DEMO 数据，但这不代表实时 OTA 价格。

## 当前范围

- 响应式网页，支持手机和桌面端
- 加拿大、日本各三条区域级路线
- 偏好匹配、价格阈值、时间与交通成本综合排序
- 统一 OTA 报价接口、平台接入状态和演示降级
- 推荐卡片内展示可折叠的往返机票组合
- 报价来源、抓价时间及官网核验能力
- 方案选择、摘要复制和分享
- 表单条件保存在浏览器本地

未配置商务凭证时，页面使用明确标注的演示报价。当前已实现同程/艺龙国际机票服务端适配器；其他平台在取得官方接口文档与授权后按相同的标准报价结构接入。

## 同程实时接口

参考 `.env.example` 设置环境变量后启动：

```bash
set -a
source .env
set +a
node server.cjs
```

服务端调用 `air.iflight.search`，不会向浏览器暴露密钥。完整平台能力和报价排序规则见 `docs/ota-integration-matrix.md`。

## 验证

服务启动后运行：
